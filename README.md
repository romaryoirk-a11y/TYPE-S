# 💬 Мессенджер

Простой, но функциональный мессенджер с real-time обменом сообщениями, группами, каналами, файлами, push-уведомлениями и аватарами.

## ✨ Возможности

- 💬 Личные чаты и общий чат
- 👥 Группы и 📢 каналы
- 📎 Отправка файлов и картинок (drag & drop)
- ✅ Статусы «доставлено» и «прочитано»
- 🖼 Загрузка аватара и смена имени
- 🔔 Web Push уведомления
- 💾 Сохранение истории на сервере
- 📱 Адаптивный дизайн

## 🚀 Запуск локально

```bash
npm install
npm start
