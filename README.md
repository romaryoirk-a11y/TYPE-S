# 💬 Мессенджер

Простой, но функциональный мессенджер с real-time обменом сообщениями.

## ✨ Возможности

- 💬 Личные чаты, группы и каналы
- 📎 Файлы, фото, видео, аудио (drag & drop)
- ✅ Статусы «доставлено» и «прочитано»
- 🖼 Аватары и профили
- 🔔 Web Push уведомления
- 💾 Сохранение истории на сервере
- 🔐 Вход по @username с любого устройства
- 📱 Адаптивный дизайн

## 🚀 Локальный запуск

```bash
npm install
npm start
